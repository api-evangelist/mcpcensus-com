The MCP Census checks public evidence for an MCP server and returns PASS, REVIEW, BLOCK, or UNKNOWN. It offers a free tier of 10 lookups per day without signup, providing REST and MCP endpoints for agents. The service helps users verify health and ownership of over 56,000 MCP servers, and includes audit capabilities for whole MCP configurations.

**Areas:** MCP · Census · Verification · API · PublicEvidence

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for MCP Census: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
